# Watermark font

`texgyreheros-regular.otf` is TeX Gyre Heros Regular, version 2.004, a
Helvetica-like typeface by B. Jackowski and J. M. Nowacki for the TeX users
groups. Downloaded unmodified from CTAN:
https://mirrors.ctan.org/fonts/tex-gyre/opentype/texgyreheros-regular.otf

It is released under the GUST Font License (`GUST-FONT-LICENSE.txt`, which in
turn refers to the LaTeX Project Public License 1.3c or later).

photo-sync always draws the watermark with this file, so the mark looks the
same on a Mac and in the slim container image (which has no Helvetica). Its
SHA-256 is part of the render fingerprint: replacing the file re-renders every
photo once.
